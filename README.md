# 🧹 MaxAqtab Cleaning & Skincare Company Website

## 🌐 Overview
**MaxAqtab** is a professional corporate website for a **cleaning and skincare company**, designed to present the company's profile, products, and brands, while providing a seamless way for customers to get in touch.  

The website includes a **full admin dashboard**, allowing the company to manage products, brands, and website settings efficiently.

> **Note:** The website was not developed from scratch; however, the **design was fully revamped** for a modern, responsive, and user-friendly experience.

**Live Website:** [https://www.maxaqtab.com/](https://www.maxaqtab.com/)

---

## 🚀 Features

### 🌟 Frontend Features
- **Company Overview** — Clear presentation of the company's cleaning services and skincare products.  
- **Products & Brands** — Showcase the products offered along with associated brands.  
- **Responsive Design** — Works smoothly on desktops, tablets, and mobile devices.  
- **Contact Form** — Allows users to send inquiries directly to the company email.  
- **Modern UI** — Redesigned layout, typography, and color scheme for a professional look.  

---

### 🏢 Admin Dashboard
- **Full Admin Dashboard** — Complete access to manage all website content.  
- **Product Management** — Add, edit, and delete cleaning and skincare products.  
- **Brand Management** — Easily manage and update company brands.  
- **Site Settings** — Modify contact info, display settings, and other configurations.  
- **User-Friendly Interface** — Designed for non-technical users to control content without coding.
